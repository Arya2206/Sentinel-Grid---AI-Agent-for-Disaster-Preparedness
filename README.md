# SentinelGrid — Emergency Guide

GitHub-ready source package for **SentinelGrid UserFirst**.

## Live demo

https://sentinelgrid.hatchable.site

## Project

- Project: SentinelGrid UserFirst
- Version: 3
- Status: Live
- Platform: Hatchable

## Features

- Flash Flood, Wildfire, Cyclone and Earthquake guidance
- Browser live-location capture
- Emergency dialer shortcut to 112
- Nearby shelter lookup using OpenStreetMap / Overpass
- Safe-status SMS composer with optional location
- Live safety map coordinates
- Personal checklist with progress and ready state
- Responsive mobile layout

## Structure

```text
public/
  index.html
  styles.css
  app.js
  checklist.css

api/
  shelters.js
```

## GitHub

Upload the contents of this repository to your GitHub repository. The `public` files form the frontend and `api/shelters.js` provides the shelter lookup endpoint.

## Evidence

The live demo URL can be submitted together with this source repository as evidence of the deployed project.

## Important

This is a demonstration/safety-assistance interface. For an actual emergency, use official emergency services and follow official local instructions.
